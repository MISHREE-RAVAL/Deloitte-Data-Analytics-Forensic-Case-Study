# Deloitte-Data-Analytics-Forensic-Case-Study
This repository contains technical solutions for the Deloitte Australia Data Analytics Simulation. The project focuses on two core domains: Industrial IoT Telemetry Analysis and Forensic Data Classification.
🛠️ Phase 1: IoT Telemetry Engineering (Tableau)Objective: Transform raw sensor logs from Daikibo’s global factories into actionable downtime metrics.Challenge: Data was provided in raw JSON format with inconsistent "Status" casing.Technical Implementation: * Ingested JSON data into Tableau Public.Metric Engineering: Created a calculated measure to quantify downtime:$$IF [Status] = 'unhealthy' THEN 10 ELSE 0 END$$Key Insight: Discovered that the Berlin factory had the highest cumulative downtime ($>1,000$ mins), indicating a need for immediate maintenance.🔍 Phase 2: Forensic Data Classification (Excel)Objective: Audit corporate compensation data to identify systemic inequality "Red Flags."Logic Applied: Used an Absolute Variance model to classify the Equality Class based on deviation scores.Classification Tiers:Fair: $|Score| \leq 10$Unfair: $10 < |Score| \leq 20$Highly Discriminative: $|Score| > 20$Impact: Automated the identification of high-risk outliers for forensic investigators.🧰 Tech StackBI Tools: Tableau Public (Dashboarding & Data Viz)Data Analysis: Microsoft Excel (Logic Functions & Forensic Audit)Data Formats: JSON, XLSX
